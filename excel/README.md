# Ejercicios resueltos en Excel

Un libro `.xlsx` por ejercicio (p. ej. reformado de metano con dos
reacciones simultáneas). Convención sugerida de nombre:
`ejN_tema.xlsx` o `parcialN_pM.xlsx`.

Los temporales de Office (`~$*.xlsx`) están excluidos por `.gitignore`.

> Pendiente: aún no hay libros aquí — al crear esta carpeta no se encontró
> ningún .xlsx de ejercicios en la carpeta del curso (solo la base de datos,
> que vive en `tablas_sva/`). Copia aquí tus libros cuando los tengas.
